## 🚀 Features

| Feature | Description |
|---------|-------------|
| 🔍 **Search** | Filter users by username in real-time |
| 📅 **Sort** | Sort by date (newest/oldest) or alphabetically |
| 🔗 **Bulk Open** | Open multiple profiles at once with custom count |
| ❌ **Bulk Dismiss** | Remove multiple accounts with undo support |
| 💾 **Export JSON** | Export remaining users to JSON file |
| 🎨 **Dark Theme** | Eye-friendly dark interface |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |
| 💾 **Auto-save** | Remembers dismissed accounts automatically |

## 📋 Requirements

- 🐍 Python 3.6+
- 📁 Instagram export data (`InstaNoBack_NonFollowers.json`)
